# Student Performance Analytics Engine

## 1. Introduction
Student Performance Analytics Engine is a simple Python project used to analyze the marks of students in different subjects. It uses NumPy to perform basic calculations and find student performance.

## 2. Objectives
- To store student marks.
- To calculate average marks.
- To find the class topper.
- To find the highest and lowest marks.
- To count passed and failed students.
- To calculate the pass percentage.

## 3. Technologies Used
- Python
- NumPy
- Google Colab

## 4. Subjects
1. Python
2. Maths
3. English
4. Java
5. Web Development

## 5. Features
- Generates marks for 10 students.
- Displays student marks.
- Calculates student-wise averages.
- Calculates subject-wise averages.
- Finds the class topper.
- Finds highest and lowest marks.
- Displays the number of passed and failed students.
- Generates a final performance report.

## 6. How to Run the Project
1. Open Google Colab.
2. Open the Student Performance Analytics Engine notebook.
3. Run the first cell to import NumPy.
4. Run all the remaining cells one by one.
5. View the final student performance report.

## 7. Conclusion
This project helps in understanding student performance using basic Python programming and NumPy. It makes calculations easier and saves time.
